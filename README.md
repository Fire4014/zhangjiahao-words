# 《张佳昊今天背单词了没》

一个离线双击即玩的单机网页小游戏：显示一个六级单词，下方 4 个选项（1 个正确释义 + 2 个错误释义 + 1 个「不会诶」）。旁边站着一位拿锤子的监督女孩——答对喊「张佳昊真棒」，答错就敲脑袋，选「不会诶」温柔提示并自动记入错题本。

## 怎么玩

直接双击 `index.html`，用 Chrome / Edge / Safari（含手机浏览器）打开即可，无需联网、无需安装任何东西。

## 目录结构

```
index.html          页面骨架
css/style.css       全部样式与动画
js/game.js          游戏逻辑、音效合成、存档
data/words.js       60 个六级核心词（4 关 × 15 词）
assets/img/         角色照片（可选，见下）
assets/audio/       真实音效（可选，见下）
```

## 玩法与流程

- 开始卡片：左趴张佳昊、右趴监督女孩，只有「Yes!」和「of course!」两个按钮。
- 选关页：4 关难度递增，未解锁置灰，显示通关最佳成绩。
- 答题页：大号单词 + 音标 + 词性；四个选项。
  - 答对：播「答对 + 哇！」音效，女孩崇拜表情喊「张佳昊真棒」。
  - 答错：女孩邪恶表情、锤子砸下命中闪白，正确项高亮、所选错误项标红，张佳昊头晕绕星约 1.5 秒后恢复。
  - 「不会诶」：记入错题本（原因「不会」），展示正确答案与温和提示，不敲脑袋。
- 结算页：显示正确率与本关错词，并解锁下一关。
- 错题本：入口在右上角，按词展开完整字段（音标/词性/变形/派生/形近/反义/词组/双语例句），标注「答错 / 不会」，支持导出 JSON 备份与清空。

## 进度保存

关卡解锁、各关最佳成绩、错题本都保存在浏览器 `localStorage`（键名前缀 `zjhw_`）。清缓存会丢失，重要数据请用错题本的「导出备份」。

## 放入你的照片（可选）

默认用 emoji 占位，照片一到即自动生效。把透明底 PNG 放进 `assets/img/`：

- 张佳昊通用图：`zhangjiahao.png`
- 监督女孩通用图：`girl.png`
- 各状态专属图（缺省时回退到通用图，再回退到 emoji）：
  - 张佳昊：`zhangjiahao_lie.png`（趴）、`zhangjiahao_idle.png`（待机）、`zhangjiahao_hit.png`（挨锤）、`zhangjiahao_dizzy.png`（头晕）、`zhangjiahao_recover.png`（恢复）
  - 女孩：`girl_lie.png`、`girl_idle.png`、`girl_happy.png`（崇拜）、`girl_evil.png`（邪恶）、`girl_encourage.png`（鼓励）

只有单张图也没关系，表情变化会靠气泡、爱心、星星、汗滴等辅助元素补齐。

## 放入真实音效（可选）

当前音效用 Web Audio 实时合成，离线即可发声。若想换成真人/真实音效，把文件放进 `assets/audio/`：

- `ready.mp3` 准备
- `correct.mp3` 答对
- `wow.mp3` 哇！
- `wrong.mp3` 答错
- `hit.mp3` 锤击
- `hint.mp3` 提示

同名文件存在时会自动优先播放，否则回退到合成音效（mp3/wav 均可）。

## 技术说明

- 纯原生 HTML/CSS/JS，零框架、零构建、零依赖。
- 词库用全局变量 `const WORDS` 内嵌，不用 `fetch`，避免 `file://` 下的跨域限制。
- 页面右上角有静音开关，状态也会被记住。
